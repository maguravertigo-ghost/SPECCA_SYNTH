# SPECCA_SYNTH

Браузерный MIDI-редактор: аранжировщик, пиано-ролл и воспроизведение через SpessaSynth и SoundFont.

**Запуск на Windows:** откройте `start.bat`. Сервер найдёт свободный порт, начиная с 8787, и откроет `http://localhost:<порт>/` в браузере по умолчанию. Отдельный профиль браузера и файлы журналов не создаются. Для остановки нажмите `Ctrl+C` в окне сервера. Запуск из терминала: `npm start -- --open` (или `npm start`, чтобы открыть адрес вручную).

### Обновление локальной копии (Windows)

Закройте запущенный сервер (`Ctrl+C`). В PowerShell откройте папку вашего клона (путь ниже — пример):

```powershell
cd C:\Projects\SPECCA_SYNTH
git status --short --branch
git fetch origin
git switch arena/5a01004e-specca-synth
git pull --ff-only origin arena/5a01004e-specca-synth
.\start.bat
```

Если `git status` показывает ваши правки, сначала сохраните или закоммитьте их. При первом переключении Git создаст локальную ветку из `origin/arena/5a01004e-specca-synth`. Если папка была распакована из ZIP, вместо `git pull` скачайте свежий ZIP этой ветки либо один раз клонируйте репозиторий командой `git clone --branch arena/5a01004e-specca-synth https://github.com/maguravertigo-ghost/SPECCA_SYNTH.git`. Git обновляет код, а не проекты из браузера: используйте тот же адрес и порт для доступа к локальным сохранениям.

Звук включается по первому нажатию **Play** или **Enable audio**. Статус аудио показывает, на каком этапе идёт загрузка; если она не удалась, можно нажать **Retry audio** или **Play** ещё раз. Громкость общая для аранжировщика, пиано-ролла и плеера. Если индикатор уровня движется, а звука не слышно, проверьте, не отключён ли звук у вкладки и выбрано ли нужное устройство вывода. Режим **SR → Auto** использует частоту аудиоустройства.

**SoundFont:** если сохранённого доступного банка нет, при старте открывается библиотека. **Load from this site / GitHub Pages** загружает комплектный банк и сохраняет копию в хранилище браузера (IndexedDB), не рассчитывая на HTTP-кеш. **Download to disk and use** сохраняет обычный файл; если браузер разрешает доступ к выбранному файлу, SPESSA запоминает разрешение, иначе — скачивает файл и сохраняет отдельную копию для запуска. Для своего `.sf2`/`.sf3` используйте **Link a file on disk…** (если доступно) или **Use and remember copy**. Оригиналы не отправляются на сервер.

У банка, связанного с файлом, библиотека показывает, требуется ли разрешение и не исчез ли файл. Копии в браузере независимы от исходного файла. На следующем запуске доступный выбранный банк используется с первым **Play / Enable audio**, без повторного скачивания. Сменить банк можно через **SoundFont…** или **File → Project Settings → Playback SoundFont**; переключение не меняет MIDI и применяется ко всем проектам в данном браузере и по этому адресу. **Forget** убирает запись из библиотеки, но не удаляет оригинал. При очистке данных сайта копии и выбранный банк могут исчезнуть.

Тесты: `npm test` (Node.js 22+).
Браузерные бандлы хранятся в репозитории для статической публикации. После обновления SpessaSynth пересоберите их командой `npm ci && npm run build`.

## Генерация треков

В верхнем меню **Generate** доступны три режима:

- **Compose a track…** создаёт новый эскиз с мелодией, аккордами, басом и ударными. Выберите стиль (Pop, Lo-fi, Retro / Game, Folk / World, Medieval или жанровый пресет (Techno, Trance, House, Drum & Bass, Hip-hop, R&B и другие)), настроение, тональность, набор инструментов, темп и длину (8–64 такта). При желании возьмите из MIDI контур мелодии или ритм; если есть барабанная партия, генератор может использовать её рисунок. Опция **Drum groove → Euclidean** распределяет удары бочки и хэта по сетке; она доступна также в Piano Roll для ударных.
- **MIDI variation…** меняет фразировку, ритм или оба параметра. Сохраняет раскладку клипов, инструменты и темп исходника, не транспонирует ноты на произвольные полутона.
- **New melody in a MIDI arrangement…** строит новые мелодические партии и гармонию поверх раскладки исходного MIDI. Сохраняет его инструменты, клипы (позиции и длины), изменения темпа и партию ударных, если она была. Как и обычный импорт SPESSA, не переносит всю MIDI-автоматику.

**Development → Evolving phrases** сохраняет гармонию и узнаваемый мотив, но меняет ритм, регистр и концовки повторяющихся фраз. Доступно при создании с нуля и в **New melody in a MIDI arrangement…**. Folk / World и Medieval используют дорийский или миксолидийский лад в зависимости от настроения.

MIDI обрабатывается локально, без загрузки на сервер. Чтобы повторить генерацию, используйте те же настройки и число **Seed**. Для непустого проекта SPESSA сначала предложит сохранить его в браузере; отмена оставит редактор без изменений. Результат открывается в аранжировщике: можно править отдельные ноты и клипы, сохранить проект или экспортировать MIDI. **Undo** возвращает проект, который был открыт до генерации.

### Перенос в трекер

**File → Export one MIDI (separate tracks)…** создаёт MIDI формата 1: темп и размер идут отдельной служебной дорожкой, а каждая звучащая партия — своей дорожкой с именем. Обычный **Save As MIDI…** сохраняет прежний формат. В трекере с поддержкой MIDI используйте эти дорожки как исходник: например, Lead → Pulse 1, Chords → Pulse 2, Bass → Triangle, Drums → Noise. **Pulse 2 монофонический**: аккорды нужно превратить в арпеджио или выбрать один голос. MIDI-ударные нужно назначить на звуки Noise вручную. SPESSA не создаёт NSF напрямую.

Для отдельных файлов выберите **File → Export MIDI by channel (ZIP)…**. Внутри архива — по одному `.mid` на канал с размещёнными нотами, включая заглушённые каналы. Позиции нот отсчитываются от начала трека. Распакуйте архив, затем через **File → Import MIDI as channels…** выберите один или несколько `.mid`, чтобы добавить их в текущий проект без замены существующих дорожек. Импорт сохраняет музыкальные позиции и использует темп текущего проекта. Границы и имена паттернов восстанавливаются при импорте из MIDI, а не копируются из исходного проекта.

## Редактирование композиции

- **New Project** предлагает Save / Discard / Cancel, если текущий проект изменён после создания, открытия или сохранения.
- **File → New Project / Open Project… / Open MIDI…** — создать проект с одной дорожкой ударных, открыть сохранённый в этом браузере проект или импортировать MIDI. Кнопка **BPM** слева от **SR** открывает точный ввод и ползунок темпа. При изменении начального темпа воспроизведение останавливается, а последующие изменения темпа импортированного MIDI сохраняются. **Save As MIDI…** экспортирует размещённые клипы целиком.
- **Имя канала слева** открывает его пиано-ролл. Двойной щелчок по клипу открывает именно его паттерн. **+ ADD** под каналами создаёт канал. Кнопка **Instrument** назначает этому каналу либо инструмент (класс и пресет), либо набор ударных. Ноты при смене звука остаются на месте.
- **Сетка аранжировщика:** левая кнопка на пустом месте рисует клип, перетаскивание клипа перемещает его по тактам, правая кнопка удаляет его. Кнопка **← Arranger** возвращает из пиано-ролла.
- **New pattern** создаёт следующий паттерн канала (`10.1`, `10.2`, …). После импорта MIDI по умолчанию это один такт в размере исходника. Поле **Bars** меняет длину выбранного паттерна во всех его клипах и не даёт обрезать ноты или наложить клипы друг на друга; **Delete pattern** удаляет паттерн во всех его размещениях. **Edit → Undo/Redo** (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z) хранит историю текущего проекта в этой вкладке.
- **Snap → Grid / ⅓ step / Free** задаёт точность перемещения и изменения длины нот; **Alt** временно отключает привязку. Такты и группы из четырёх шагов выделены разными оттенками.
- **Generate** справа от **Delete pattern** заполняет текущий паттерн редактируемыми нотами. Для мелодического канала выберите тональность, лад и ритм (аккорды, мелодию, арпеджио или синкопы); для ударных — жанровый грув и роль паттерна: **Full groove**, **Intro**, **Breakdown**, **Transition / Fill** или **Ending**. Переход оставляет начало последнего такта под основной ритм, а на конце добавляет сбивку. По умолчанию существующие ноты заменяются; чтобы их сохранить, выберите **Keep and add**. Для баса, мелодии и аккомпанемента можно выбрать **Genre**. Паттерны одного жанра, тональности, лада и длины используют общий гармонический план. Кнопки 2/4/8 выбирают быстрые длительности, список **Dur** содержит также целые, короткие, триольные и пунктирные длительности. Генерацию можно отменить через **Undo**.
- Повторные клипы ссылаются на один паттерн: правка нот в пиано-ролле слышна во всех его копиях. Удаление клипа не удаляет ноты самого паттерна.
- **Ctrl/Cmd+C, X, V** (или **Edit**) копируют, вырезают и вставляют выбранные ноты. Клик по линейке пиано-ролла также задаёт позицию вставки; без него редактор ищет свободное место в паттерне.
- **Player → Open Player… / F5** проигрывает исходный MIDI из плейлиста, не трогая проект. В оверлее можно добавлять файлы, ставить воспроизведение на паузу, перематывать и переключать треки. Если в оригинале пропадают голоса, включите **Compatible**: он разводит партии по отдельным каналам и подбирает доступные пресеты SoundFont, но не переносит всю MIDI-автоматику.
- **File → Open MIDI…** создаёт редактируемую аранжировку: ноты сгруппированы по каналам и инструментам, точные повторы используют общий паттерн. Если на дорожке несколько паттернов, выделите нужный клип и нажмите имя канала слева. Для точного воспроизведения исходного файла, включая его MIDI-автоматику, используйте плеер.

- Клик по верхней линейке аранжировщика или пиано-ролла ставит головку воспроизведения. Если музыка играет, она продолжает играть с нового места; если остановлена, следующее **Play** начнётся с выбранной позиции. Кнопки **⏮/⏭** ставят головку в начало или конец.
- При импорте дорожки, повторно использующие MIDI-канал, и партии с разными программами получают отдельные дорожки. При необходимости создаются дополнительные MIDI-порты, чтобы партии за пределами первых 16 не сливались.

- ПКМ по верхней полосе маркеров сводит их и отключает повтор диапазона. Потяните левый маркер влево, затем правый вправо. Кнопка **Loop entire track** слева от **Loop** ставит диапазон от начала до конца звучащей части. Если изменить клипы во время проигрывания, аранжировка обновится без ручного Stop/Play.
- **MIX** в Piano Roll включён по умолчанию. Двойной щелчок по клипу задаёт точный участок аранжировки: **Play** проигрывает его в пределах паттерна со всеми незаглушёнными каналами. При входе через имя канала берётся первое размещение выбранного паттерна; если его ещё нет, редактор подставляет его в начало трека. **MIX** можно выключить, чтобы услышать только паттерн. **Loop** повторяет тот же участок.
- В Piano Roll слева от общей громкости индикатор показывает состояние текущего канала: зелёный **ON** или серый **MUTE**. Изменить состояние можно в микшере.
- Микшер слева от транспорта. В редакторе он управляет каналами проекта; ползунок **Pan** меняет размещение канала в стерео (двойной щелчок возвращает центр), панорама сохраняется в проекте и MIDI как CC10. Панораму по времени и эффекты эта версия не автоматизирует. В плеере микшер управляет портами и каналами текущего MIDI, не меняя проект. В окне **Instrument** фильтр банков показывает доступные банки загруженного SoundFont, когда их больше одного.

- **FIX** в Piano Roll предлагает тональность и показывает, сколько выбранных нот (или нот всего паттерна) можно приблизить к гамме на 1–2 полутона. Время, длина и громкость нот не меняются. Это правка высоты, а не автоматическое разделение голосов. Доступно Undo.
- ПКМ по имени канала → **Clone channel** вставляет независимую копию с инструментом, настройками, паттернами и клипами сразу под оригиналом.
- ПКМ по имени канала → **Draw pattern** выбирает паттерн, который рисуется на пустой сетке. Его имя также видно в подсказке канала.
- Для визуальных пометок выберите **Comment** в категории канала. Откройте паттерн и заполните **Notes**: текст будет виден в клипах и сохранится с проектом, но не попадёт в MIDI или в микшер. Потяните правый край клипа, чтобы изменить длину паттерна в целых тактах: минимум один такт, максимум — без наложения на соседние клипы. Изменение применяется ко всем копиям и отменяется через Undo.

- При воспроизведении аранжировки головка идёт до центра видимой сетки, а затем сетка прокручивается за ней. **Pause** оставляет позицию, **Stop** и **To start** возвращают вид к началу. **To start** выключает короткий луп, не стирая его границы. Повтор можно снова включить кнопкой **Loop**. **To end** останавливает воспроизведение и оставляет головку в конце трека; настройки лупа сохраняются.


### Части мелодических фраз (v1.9.1)

В Piano Roll → Generate список **Section** теперь есть также для Melody, Bass line, Chords, Arpeggio и Syncopated chords:
- **Main phrase** — основная партия;
- **Intro** — более редкое и мягкое вступление;
- **Breakdown / sparse** — разреженная партия с более длинными нотами;
- **Transition / Fill** — заключительная пробежка в пределах выбранной гаммы;
- **Ending** — завершение на тонике с паузой перед границей паттерна.

Это редактируемые ноты, а не автоматизация громкости. Genre, Key, Scale, Replace / Keep and add и Undo работают как раньше. Для согласованного завершения выбирайте Ending у мелодии, баса и ударных.


### Автоматизация паттерна — Pan / Fade (v1.10.0)

**Effects** в Piano Roll включает полупрозрачный слой над нотами. Редактор кривой показывает **весь паттерн**, независимо от текущего увеличения сетки нот. Выберите Pan или Fade, добавьте точки щелчком и перемещайте их мышью. ПКМ по точке удаляет её. Пресеты Rise, Fall, Neutral и переключатель Smooth задают прямые или плавные кубические сегменты с горизонтальными касательными (ручных управляющих ручек Безье пока нет).

Кнопка Effects показывает созданные кривые. Скрытие редактора не отключает автоматизацию; **Bypass** отключает только выбранную кривую, **Remove curve** удаляет её. Изменение жестом — один шаг Undo. Кривые сохраняются в проекте и копируются вместе с паттерном.

Fade передаётся через MIDI Expression CC11: 100% оставляет уровень канала, 0% даёт тишину. Pan — смещение относительно панорамы микшера; при центральном положении микшера доступен полный диапазон L–R. Каждая размещённая копия повторяет кривую; в конце значения возвращаются к исходным. Управление работает через общий MIDI-планировщик в Piano Roll (включая MIX), аранжировщике и MIDI-экспорте. Кривые преобразуются в дискретные MIDI-события, поэтому это не непрерывная аудиочастотная модуляция. Импорт MIDI пока не восстанавливает кривые обратно в редактор автоматизации.

Как и прочие MIDI-контроллеры, автоматизация действует на канал, а не на изолированный голос: при перекрытии паттернов одного канала события будут конкурировать. Для независимого движения используйте разные каналы. Ручные касательные Безье, WAV-экспорт добавлен в v1.15.0 (см. ниже). Звуковые эффекты добавлены в v1.12.0 (см. ниже).


### Обзор автоматизации (v1.11.0)

- **Automation view** в панели аранжировщика затемняет музыкальные клипы и показывает Pan (голубой) и Fade (оранжевый). Это переключатель просмотра, он не меняет звук или проект. Ноты остаются бледным фоном; Comment не затемняется. Обычное редактирование клипов сохраняется.
- Цветные метки **Pan / Fade** видны на клипах и без режима просмотра. Отключённая через Bypass кривая помечена **off**, а в режиме просмотра рисуется пунктиром. Tooltip клипа перечисляет автоматизацию. Пустые кривые не показываются.
- В **Project mixer** под каналом есть **Pattern automation**: число активных паттернов / общее число паттернов с кривой данного типа. Сводка включает неразмещённые паттерны и не считает копии клипа отдельными паттернами. Это информация об автоматизации паттернов, не список звуковых обработчиков канала.

Shift пока не перехватывается; режим включается отдельной кнопкой и не добавляет запись Undo.


### Звуковые эффекты (v1.12.0)

**Project mixer → Audio effects…** или **Audio FX…** в Piano Roll открывают параметры встроенных в SpessaSynth общих Roland GS-процессоров:

- **Reverb**: тип пространства (0–5), затухание, предзадержка в миллисекундах, damping и уровень возврата.
- **Chorus**: скорость, глубина, задержка, feedback, damping и уровень возврата.
- **Delay**: время по шкале GS (не миллисекунды), соотношения времени левого/правого повторов, feedback (64 — без обратной связи), damping и возврат. Синхронизации с BPM пока нет.

Под каждым каналом проектного микшера находятся три **send**: Reverb / Chorus / Delay (0–127). Это посылы в общие параллельные шины, а не три последовательных insert-эффекта. Нулевой посыл не отправляет канал в соответствующую шину. Переключатель Enabled у эффекта отключает общий возврат, сохраняя настройки. При изменении параметров они слышны сразу; завершение жеста сохраняется одним шагом Undo. Изменения могут дать краткое перестроение звукового хвоста.

Настройки шин и посылов сохраняются в JSON-проекте, работают в аранжировщике и Piano Roll/MIX. Отдельный Player по-прежнему воспроизводит настройки самого MIDI. Для старых проектов до первого изменения FX-параметра или посыла сохраняется прежняя схема движка; при включении новой схемы начальный посыл Reverb равен 40, Chorus и Delay — 0. Параметры общих шин влияют на все каналы, которые в них отправлены. Через Audio FX в Piano Roll открываются именно общие параметры, не эффект текущего паттерна.

Существующий MIDI-экспорт кодирует GS-параметры и CC91/93/94, однако другой синтезатор может их не поддерживать или звучать иначе. Импорт MIDI пока не восстанавливает панели FX. WAV-экспорт добавлен в v1.15.0 (см. ниже). Цепочек независимых insert-эффектов и автоматизации параметров шин пока нет.


### Chiptune Synth (v1.13.0)

В окне **Instrument** для текущего канала (или при добавлении канала) выберите **Category → Chiptune Synth**. Доступны Pulse, Triangle и Noise; пресеты Chip Lead, Narrow Pulse, Triangle Bass, Noise Snare, Noise Hat; ширина Pulse 12.5/25/50/75% и огибающая Attack / Decay / Sustain / Release. Attack, Decay, Release задаются в секундах, Sustain — 0–1. Изменения применяются кнопкой Apply; Cancel сохраняет прежний инструмент. Это источник звука всего канала, а не эффект отдельного паттерна. Возврат к SoundFont — через Category → SoundFont instruments.

Это минимальный полифонический инструмент на программно созданных зацикленных PCM-волнах и огибающей штатного SoundFont-движка. Он не эмулирует NES и пока не имеет Mono/Glide, фильтра, pitch sweep, vibrato, Saw/Sine или FM. Noise не транспонируется по высоте. Генератор нот для Noise пока остаётся мелодическим: шумовые ударные можно расставить вручную; отдельного drum map для этого источника нет.

Общий движок сохраняет точное время MIDI-нот, MIX, mute/volume/pan, loop/seek, Pan/Fade automation и посылы звуковых эффектов. SoundFont для обычных каналов остаётся загруженным; библиотека SoundFont и его выбор при запуске работают как раньше. Банк чиптюн-волн создаётся локально при воспроизведении и не требует скачивания. В этой версии используются внутренние банки MSB 100–115, поэтому не назначайте вручную эти же патчи обычным каналам, если ваш сторонний SoundFont их использует.

**JSON-проект** хранит источник и все параметры, клон канала получает независимые настройки. **Обычный MIDI-экспорт не содержит созданных волн/ADSR**: вместо них записываются GM Square Lead, Synth Bass или Gunshot для Noise — это приближение, не сохранение звучания. Импорт такого MIDI не восстанавливает Chiptune Synth. Player остаётся отдельным MIDI-плеером; NSF-импорт/экспорт не добавлен. WAV-экспорт добавлен в v1.15.0 (см. ниже).

Кнопка редактора кривых в Piano Roll теперь называется **Automation**, а **Audio FX…** открывает параметры Reverb/Chorus/Delay.


В v1.13.1 справа от числовых полей Attack / Decay / Sustain / Release добавлены ползунки для быстрой настройки. Они синхронизируются с точным вводом и пресетами; применение и отмена по-прежнему выполняются через Apply / Cancel.


### Ручная клавиатура и запись (v1.14.0)

Кнопка **▥ Piano** в Piano Roll раскрывает горизонтальную клавиатуру с подписями нот и клавиш компьютера. Играйте мышью/касанием или физическими клавишами (русская раскладка тоже работает):

- нижняя октава: **Z S X D C V G B H N J M**;
- верхняя октава и завершающая C: **Q 2 W 3 E R 5 T 6 Y 7 U I**;
- **− Oct / + Oct** меняют диапазон, вплоть до MIDI 0–127;
- **Velocity** задаёт силу последующих нажатий, поддерживается полифония.

Клавиши визуально утапливаются при нажатии. Источник — текущий канал: SoundFont, Chiptune Synth или ударный набор. Для ударных выберите диапазон с MIDI 35/36 (низкий B / C2), чтобы получить бас-бочку. Настройки канала (mute, volume, pan и посылы) применяются и к ручному звуку. Прослушивание не запускает транспорт и не изменяет паттерн. Оно использует отдельный служебный голосовой канал, чтобы отпускание ручной ноты не глушило ноту той же высоты из аранжировки. Автоматизация паттерна управляет записанными/секвенсорными нотами, но не отдельным ручным предпросмотром.

**● REC** только вооружает запись. После этого нажмите Play, в том числе в пустом паттерне, и играйте. Ноты видны на сетке во время удержания, а при отпускании фиксируются с учётом **Snap**. Free оставляет точность до MIDI-тика; запись не имеет компенсации аппаратной задержки. На границе лупа нота разделяется. Очень долгое удержание ограничено двумя длинами паттерна при сохранении, чтобы не плодить бесконечные одинаковые ноты.

Режим — **overdub**: прежние ноты сохраняются, при записи слышны они и ручная игра. Новые ноты добавляются в проигрываемую секвенцию после завершения дубля, а не на каждом нажатии; это предотвращает двойную атаку и перезагрузку на каждой ноте. Дубль завершается через Stop / REC off, закрытие клавиатуры, переход/перемотку или потерю фокуса и сохраняется одним шагом Undo. Метронома и отсчёта пока нет. Ручное прослушивание работает и без REC, запись — только при запущенном транспорте. При вводе в текстовые поля и в модальных окнах музыкальные клавиши не перехватываются, Ctrl/Cmd+C/X/V/Z остаются командами редактора.

**All notes off**, закрытие панели, смена контекста, открытие диалога и потеря фокуса снимают ручные ноты, включая ожидающие запуска аудио. Панель недоступна на Comment. JSON/MIDI сохраняют записанные ноты обычным способом; правила переноса Chiptune-звучания остаются прежними.


### Исправления REC / live keyboard (v1.14.1)

Исправлена подмена ручного Chiptune на Grand Piano после повтора лупа: выбранный патч служебного канала и его основные контроллеры защищены от MIDI reset. Перед загрузкой следующего MIDI блокировки снимаются, чтобы не влиять на обычные или многопортовые файлы. Проверяется фактический патч, а не только кеш настроек. Клавиатура заранее подготавливает голос при открытии и старте транспорта; после подготовки обычные note-on отправляются напрямую, без очереди и повторной подготовки банка на каждую клавишу.

Исправлены практически неслышные однотиковые ноты при быстрых нажатиях с включённым Snap: минимум новой записанной ноты теперь один шаг выбранной сетки. У границы лупа начало остаётся на последней допустимой линии сетки. **Snap → Free** сохраняет фактическое время с точностью до тика. Ранее записанные однотиковые ноты автоматически не изменяются.


### Merge channels и WAV (v1.15.0)

**ПКМ по каналу → Merge channels ↓…** объединяет текущий канал с непосредственно следующим в **видимом порядке**. Текущий канал остаётся основой: сохраняются его инструмент/Chiptune, mute, громкость, pan и посылы. Все паттерны нижнего канала переносятся в него, ноты переназначаются на его MIDI-канал, нижний канал удаляется. Исходные позиции, длины, повторы клипов и неразмещённые паттерны сохраняются. Перенесённые паттерны доступны в селекторе верхнего канала; это не автоматическое объединение всех нот в один длинный паттерн. Перекрывающиеся клипы остаются перекрывающимися; их кривые автоматизации теперь действуют на общий канал и могут конкурировать. Изменение звучания при разных инструментах ожидаемо. Есть подтверждение и единый Undo/Redo; для последнего канала или пары с Comment действие недоступно.

**File → Export WAV…** делает офлайн-рендер всей размещённой аранжировки без бесконечных повторов LOOP и без захвата микрофона/системного звука:
- stereo PCM WAV 16-bit, 44.1 или 48 kHz;
- текущий загруженный SoundFont и программный Chiptune, tempo map, Pan/Fade, канальные громкости/mute/pan, Reverb/Chorus/Delay и текущая мастер-громкость;
- хвост эффектов задаётся вручную: 0–30 секунд, по умолчанию 8; длинное затухание может требовать большего значения;
- без автоматической нормализации; при выходе за пределы PCM появляется предупреждение о clipped samples — уменьшите мастер-громкость и повторите экспорт;
- первая версия ограничена 5 минутами вместе с хвостом из-за хранения PCM в памяти; экспорт участка и автоматическое определение конца хвоста пока не добавлены.

Воспроизведение перед экспортом останавливается, сам экспорт не звучит через колонки и не меняет проект. Cancel не скачивает результат; при уже идущем офлайн-рендере отмена дожидается завершения текущего этапа. Для экспорта нужны размещённые в аранжировщике паттерны — неразмещённый паттерн сам по себе в WAV не входит. WAV содержит готовое звучание Chiptune, в отличие от приближённой GM-подстановки в обычном MIDI. Рендер проверен в Chromium с AudioWorklet / OfflineAudioContext; если браузер их не поддерживает, окно покажет ошибку. Совпадение архитектуры движка не означает побитовой идентичности отдельных запусков модулируемых/случайных эффектов.


### Выбор проекта и общие кнопки (v1.24.0)

В **Saved projects** строка выбирается кликом и подсвечивается; также работают ↑ / ↓ и Home / End. Сам выбор не открывает композицию. **Open / Clone / Rename / Delete** расположены одним рядом внизу слева и действуют на выделенный проект. При пустом списке или отсутствии результатов поиска они недоступны.

Счётчик всех сохранённых проектов перенесён в заголовок справа. **Close** остаётся внизу справа; крестик в правом верхнем углу и Esc также закрывают окно. Список прокручивается независимо от нижних кнопок. После переименования выделение сохраняется на новом имени, после клонирования выбирается копия, после удаления — соседний проект.

### Название композиции и сохранённые проекты (v1.23.0)

Название композиции отображается **белым справа внизу, в общей нижней строке подсказок (также видна в Piano Roll)**. Длинное имя сокращается многоточием; полный текст доступен при наведении. Сообщения состояния также перенесены из верхней панели вниз, чтобы не сдвигать её кнопки.

**File → Open Project…** открывает менеджер **Saved projects**, в том числе при пустом списке. Есть поиск по имени, дата сохранения, число каналов/паттернов и действия:

- **Open** — открыть сохранённую композицию; при несохранённых правках сначала Save / Discard / Cancel.
- **Rename** — переименовать запись и имя внутри проекта. Если этот сохранённый проект открыт, обновляется его рабочее имя без потери несохранённых нот. Занятое имя не перезаписывается.
- **Clone** — создать независимую копию сохранённой версии под новым именем (не снимок ещё не сохранённых правок). WAV-ассеты остаются общими ссылками на данные браузера.
- **Delete** — удалить сохранённую запись после подтверждения. Открытая композиция продолжает работать, её можно сохранить снова. WAV-данные не удаляются, чтобы не повредить другие копии.

Это локальная библиотека проектов данного адреса в этом браузере, не файловый менеджер диска. Изменения списка не являются шагами музыкального Undo. При ошибке записи хранилища менеджер показывает сообщение, не удаляя исходную запись.

### Точное позиционирование головки (v1.22.0)

Справа в полосе **Time markers** расположены:

- **Playhead** — текущая позиция в формате **ЧЧ:ММ:СС**, с необязательной дробной частью до миллисекунд (`00:00:03.125`). Введите время и нажмите Enter или перейдите из поля, чтобы установить головку. Esc отменяет ввод. Пока поле редактируется, воспроизведение не перезаписывает текст.
- **Snap bars: ON/OFF** — привязка головки к ближайшему началу такта **B1, B2, B3…** при клике/перетаскивании по линейке аранжировщика. По умолчанию выключена; выбор запоминается в браузере, а не в проекте. Ввод таймкода и переходы к меткам остаются точными и не округляются к тактам.

Установка позиции не запускает остановленное/приостановленное воспроизведение. Во время проигрывания переход продолжает его с выбранной позиции. Время ограничено доступной длительностью аранжировки (для пустого проекта — видимой начальной шкалой). Позиция и переключатель не создают шагов Undo.

Дублирующая нижняя кнопка **Import WAV…** удалена; **File → Import WAV as audio channel…** и замена/relink WAV из меню аудиоканала сохранены.

### Сетка Pan/Fade automation (v1.21.0)

В **Automation** появилась сетка с настройками:

- **X grid → Piano Roll** по умолчанию использует временную сетку Piano Roll с тем же zoom и горизонтальной прокруткой. Можно выбрать другой шаг: 1/4–1/64, триоли или такт. Существующие точки не квантуются автоматически.
- **Y grid (px)** — расстояние между горизонтальными линиями, по умолчанию 20 px (высота строки нот). Это только разметка: значение точки по Y всегда свободное.
- **Snap X: ON/OFF** включает/отключает привязку времени. **Snap to**: Grid, Note edges или Grid + note edges. Края нот захватываются в пределах 10 экранных пикселей; в комбинированном режиме выбирается ближайшая цель. **Note guides** показывает начало и конец нот.
- **Alt** временно отключает X-привязку. **Esc** отменяет текущее перетаскивание. Один завершённый drag — один шаг Undo; отменённый drag не меняет проект.
- Настройки сетки запоминаются в этом браузере отдельно от проекта и не создают шагов Undo. Колесо мыши, Ctrl+колесо (zoom) и Shift+колесо (горизонтальная прокрутка) работают через ту же шкалу Piano Roll.

### DPCM-слой NSF и настоящие ноты (v1.20.0)

В **File → Import NSF as notes…** добавлена включённая по умолчанию опция **DPCM layer → Include as separate audio channel**. При извлечении эмулируется чтение DMC-сэмплов через DMA из актуальных банков памяти и работа 7-битного DAC, включая прямые записи `$4011`. Выход DPCM/DAC захватывается отдельно, без Pulse/Triangle/Noise, интегрируется в PCM 44,1 кГц и очищается от DC простым high-pass 40 Гц, без нормализации. Это изолированный сэмпловый слой, а не полная эмуляция аналогового микшера NES.

При **Import channels** вместе с мелодическими дорожками добавляется отдельный **DPCM audio** с волновой формой. Его можно сдвигать, переименовывать, регулировать Volume/Pan/Mute, слушать в аранжировщике и MIX Piano Roll, включать в WAV-экспорт. Для записи без слышимых изменений DAC пустой аудиоканал не создаётся. DPCM можно отключить перед Extract; Cancel не сохраняет аудио и не меняет проект. Добавление нот и аудиоканала — одно действие Undo/Redo. Поддерживается и NSF-фрагмент только с DPCM, без мелодических нот.

**Это разные типы редактирования:** Pulse/Triangle/Noise — настоящие ноты на сетке Piano Roll; Fade automation управляет их громкостью и не заменяет их. При открытии NSF-канала это поясняется в статусе Piano Roll. DPCM пока импортируется непрерывным **аудиоклипом**, не набором редактируемых нот/ударов; нарезка на отдельные DPCM-триггеры и сэмплерные ноты — последующий этап. DPCM может содержать не только ударные, но и бас/речь/другие сэмплы.

DPCM-WAV хранится в IndexedDB этого браузера, как импортированный WAV, а проект сохраняет ссылку и положение. Для резервной копии: ПКМ по аудиоканалу → **Download source WAV…** (доступно также для обычных WAV-каналов). MIDI не переносит этот слой. После очистки базы используйте сохранённый WAV через Replace / relink WAV или повторно импортируйте NSF. Ранее импортированные проекты автоматически DPCM не получают: повторный импорт добавит новый набор каналов, поэтому удалите/заглушите старые дубликаты либо начните с нового проекта.

### Импорт NSF в редактируемые ноты (v1.19.0)

**File → Import NSF as notes…**: выберите локальный `.nsf`, композицию (**Song**), длительность 1–180 секунд и позицию (начало проекта или головка аранжировщика). **Extract / preview** запускает 6502/APU-эмуляцию в отдельном Worker и показывает количество извлечённых нот по каналам и предупреждения. **Import channels** добавляет результат к существующему проекту, не заменяя его. Cancel / Esc завершает Worker без изменений проекта. Импорт отменяется одним Undo, Redo восстанавливает его.

Это извлечение состояний музыкального драйвера, а не распознавание высоты из аудио и не готовый MIDI внутри NSF. Pulse 1, Pulse 2, Triangle и Noise становятся отдельными Chiptune-каналами с редактируемыми нотами. Если у Pulse меняется duty, его варианты идут в отдельные дорожки. Громкостная огибающая переносится в Fade automation; Noise импортируется с отслеживанием высоты для приближения скорости шумового генератора. Таймер и отклонение от ближайшего полутона сохраняются в метаданных нот. Паттерны по восемь тактов, пересекающие границу ноты разбиваются на соседние сегменты.

**Ограничения первого этапа:** NSF v1, NTSC (или dual-region в режиме NTSC), стандартный NES 2A03; размер до 4 МБ, до 50 000 нот на извлечение. Поддерживаются обычная загрузка и 4-КБ bank switching. NSFe, NSF v2, PAL-only, дополнительные чипы и `.nes`-образы игр пока отклоняются с объяснением. IRQ-driven воспроизведение не поддерживается. Неподдерживаемые адреса/невернувшийся или слишком долгий драйвер завершают импорт ошибкой, не изменяя проект.

**Звук приближённый:** состояние снимается с частотой 240 Гц, высоты округляются до полутонов, слайды и арпеджио могут стать цепочками коротких нот; нет точной эмуляции тембра/нелинейного микшера NES при проигрывании проекта. Short-mode noise приближается обычным процедурным шумом. В v1.19 DPCM/DAC-сэмпловый канал только определялся; начиная с v1.20 он может добавляться отдельным аудиослоем (см. выше). Темп NSF автоматически не определяется: абсолютное время извлечённых нот переводится в текущую tempo map проекта, BPM и уже существующие каналы не меняются. Для сравнения сохраняйте оригинальную запись; можно импортировать её как опорный WAV.

Извлечённые ноты/настройки сохраняются обычным Save, редактируются в Piano Roll и включаются в WAV-экспорт. Для повторного открытия проекта исходный NSF уже не нужен. MIDI-экспорт использует стандартные GM fallback-инструменты, а не точные NES-тембры. Обработка локальная; файл не загружается на сервер.

Эмуляционное ядро CPU/APU: **JSNES 3.0.0, Apache-2.0**; лицензия и сведения — `third_party/`. Браузерный модуль уже включён в репозиторий; для его пересборки: `npm ci` и `npm run build:nsf` (также входит в `npm run build`).

### WAV-аудиоканалы и временные метки (v1.18.0)

**Import WAV…** внизу аранжировщика или **File → Import WAV as audio channel…** добавляет запись в отдельный канал, в текущую позицию головки. На клипе рисуется волновая форма. Аудиоклип можно переместить мышью без привязки к тактам; клик по имени канала или двойной клик по клипу открывает точное стартовое время **минуты : секунды : миллисекунды** и имя. В Project mixer доступны Volume, Pan и Mute. В ПКМ-меню канала — редактирование, замена / повторная привязка WAV, клонирование, перестановка и удаление. Замена записи сохраняет стартовую позицию. Изменения поддерживают Undo/Redo.

Аудио сохраняет исходную скорость и высоту: при смене BPM его начало и длина в секундах остаются прежними, сетка MIDI меняется относительно записи. WAV играет вместе с MIDI/Chip в аранжировщике, в соответствующем временном окне **MIX** в Piano Roll и в итоговом **Export WAV**. Solo-паттерн (MIX off) не включает опорную запись. Импортированное аудио идёт в общий master с собственными Volume/Pan/Mute, без SoundFont FX sends и без паттерновой MIDI-автоматизации. Нарезка, time-stretch и аудиофейды пока не реализованы. Импорт: RIFF WAV, до 100 МБ и 30 минут на файл, при поддержке кодека браузером. Общий offline WAV-экспорт по-прежнему ограничен 5 минутами вместе с хвостом эффектов.

**Хранение:** копия WAV хранится локально в IndexedDB этого сайта/браузера; Save сохраняет в проекте ссылку, позицию и волновую форму, а не кладёт большой файл в localStorage. После перезагрузки страницы и Open Project запись восстанавливается. MIDI-файлы не содержат аудио и не являются резервной копией WAV. Сохраняйте исходные записи отдельно: очистка данных сайта, другой браузер/адрес/порт не переносят эту базу. Если копия потеряна, playback/export покажет ошибку; используйте ПКМ аудиоканала → **Replace / relink WAV…**. Аудиокопии пока не удаляются автоматически из базы при удалении канала, чтобы не разрушать Undo и другие сохранённые проекты.

**Time markers** — жёлтые опорные флажки над LOG. **+ At playhead** создаёт метку в позиции головки; диалог задаёт имя и время **MM : SS : mmm**. Для каждого компонента есть ввод с клавиатуры и стрелки ↑/↓ с шагом 1. Клик по флажку ставит головку в его время, двойной клик редактирует. Кнопки ◀ / ▶ переходят к предыдущей/следующей метке; Edit и Delete работают с выбранной. ПКМ по флажку открывает переход, редактирование имени/времени, создание в позиции головки и удаление. ПКМ по свободной полосе меток — создание. Метки не запускают остановленный playback.

От каждой метки проходит вертикальная жёлтая линия через аранжировку. Подписи с обводкой располагаются снизу вверх: их ширина измеряется в пикселях, пересекающиеся или слишком близкие подписи занимают разные ярусы. Полоса синхронизирована с горизонтальной прокруткой, при большом количестве ярусов прокручивается вертикально. Метки хранят абсолютное время в миллисекундах, не сдвигаются при изменении BPM, сохраняются в проекте и участвуют в Undo/Redo.

### Графический Chiptune Synth (v1.17.0)

В Piano Roll назначьте **Chiptune Synth** через инструмент, затем откройте **Chiptune…** рядом с инструментом. Панель показывает форму волны, редактируемую мышью ADSR и график pitch sweep. Есть Pulse / Triangle / Noise и пресеты; ширина Pulse 5–95% с шагом 0,1%, Attack / Decay / Sustain / Release, транспонирование ±36 полутонов, fine tune ±100 cents, pitch sweep ±48 полутонов с отдельным decay, low-pass cutoff и resonance.

Удерживайте тестовые клавиши в панели для прослушивания. Изменения слышны **на следующих нотах**: это не плавная модуляция уже удерживаемой ноты. График генератора показывает исходную волну, не сигнал после фильтра/эффектов. Открытие панели останавливает playback; **Apply** сохраняет звук одним действием Undo, **Cancel / Esc** возвращает прежние настройки. Параметры сохраняются в проекте и используются при WAV-экспорте; MIDI остаётся с переносимым GM fallback. PWM, vibrato и mono/glide пока не реализованы.

### Split channel — разложить партию (v1.16.0)

**ПКМ по каналу → Split channel…** разделяет его ноты на самостоятельные каналы. Для ударных доступны:
- **Drum categories**: Kick, Snare / Clap, Hi-hat, Toms, Cymbals, Percussion / Other — создаются только реально используемые группы;
- **Each MIDI note / sound**: отдельный канал для каждой высоты/звука, например Closed Hi-hat 42 и Open Hi-hat 46 отдельно.

Для мелодического канала доступно разделение по отдельным MIDI-нотам. Диалог заранее показывает число и названия результатов. Если звуков меньше двух, действие не выполняется. При нехватке свободных MIDI-каналов проект не изменяется.

Первый результат остаётся на исходном канале, остальные появляются сразу под ним в видимом порядке. Сохраняются ноты (высота, позиция, длительность, velocity), длины паттернов, позиции и повторы клипов, неразмещённые паттерны, mute/volume/pan, инструмент и посылы. Автоматизация и настройки копируются независимо: изменение одного результата не меняет соседние. Повторяющиеся клипы продолжают ссылаться на один соответствующий подпаттерн. В первой группе могут оставаться пустые клипы тех исходных паттернов, в которых нет её нот — временная разметка не сдвигается. Всё разделение — один Undo / Redo.

После разделения откройте нужную партию в Piano Roll → Instrument → Chiptune Synth: например, назначьте **Noise Hat** для Hi-hat или **Noise Snare** для Snare. Остальные каналы сохранят прежний инструмент; можно постепенно собирать чиптюн-версию исходной партии. Pulse / Triangle являются высотными инструментами, поэтому для них при необходимости подберите/транспонируйте высоту нот вручную. Автоматического преобразования kick в синтезированный pitch-sweep пока нет. WAV-экспорт сохраняет звучание выбранных чиптюн-инструментов.
