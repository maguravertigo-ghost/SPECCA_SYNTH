# SPECCA_SYNTH

Браузерный MIDI-редактор: аранжировщик, пиано-ролл и воспроизведение через SpessaSynth и SoundFont.

**Запуск на Windows:** откройте `start.bat`. Сервер найдёт свободный порт, начиная с 8787, и откроет `http://localhost:<порт>/` в браузере по умолчанию. Отдельный профиль браузера и файлы журналов не создаются. Для остановки нажмите `Ctrl+C` в окне сервера. Запуск из терминала: `npm start -- --open` (или `npm start`, чтобы открыть адрес вручную).

### Обновление локальной копии (Windows)

Закройте запущенный сервер (`Ctrl+C`). В PowerShell откройте папку вашего клона (путь ниже — пример):

```powershell
cd C:\Projects\SPECCA_SYNTH
git status --short --branch
git fetch origin
git switch arena/5a01004e-specca-synth
git pull --ff-only origin arena/5a01004e-specca-synth
.\start.bat
```

Если `git status` показывает ваши правки, сначала сохраните или закоммитьте их. При первом переключении Git создаст локальную ветку из `origin/arena/5a01004e-specca-synth`. Если папка была распакована из ZIP, вместо `git pull` скачайте свежий ZIP этой ветки либо один раз клонируйте репозиторий командой `git clone --branch arena/5a01004e-specca-synth https://github.com/maguravertigo-ghost/SPECCA_SYNTH.git`. Git обновляет код, а не проекты из браузера: используйте тот же адрес и порт для доступа к локальным сохранениям.

Звук включается по первому нажатию **Play** или **Enable audio**. Статус аудио показывает, на каком этапе идёт загрузка; если она не удалась, можно нажать **Retry audio** или **Play** ещё раз. Громкость общая для аранжировщика, пиано-ролла и плеера. Если индикатор уровня движется, а звука не слышно, проверьте, не отключён ли звук у вкладки и выбрано ли нужное устройство вывода. Режим **SR → Auto** использует частоту аудиоустройства.

**SoundFont:** при открытии страницы выберите комплектный банк с сайта, локальный `.sf2`/`.sf3` или **Edit without sound**. Синтезатор читает комплектный `soundfont.sf2` из корня сайта. На GitHub Pages браузер загружает его по сети; при `npm start` тот же файл отдаётся с вашего диска через `localhost`. Если скачивание на Pages застряло, нажмите **SoundFont…** и выберите свой `soundfont.sf2` с диска. Файл не загружается на сервер, выбор действует до перезагрузки вкладки. Если Play уже ждёт скачивания, оно отменится и воспроизведение продолжит запуск с локальным файлом.

Тесты: `npm test` (Node.js 22+).
Браузерные бандлы хранятся в репозитории для статической публикации. После обновления SpessaSynth пересоберите их командой `npm ci && npm run build`.

## Генерация треков

В верхнем меню **Generate** доступны три режима:

- **Compose a track…** создаёт новый эскиз с мелодией, аккордами, басом и ударными. Выберите стиль (Pop, Lo-fi или Retro / Game), настроение, тональность, набор инструментов, темп и длину (8–64 такта). При желании возьмите из MIDI контур мелодии или ритм; если есть барабанная партия, генератор может использовать её рисунок. Опция **Drum groove → Euclidean** распределяет удары бочки и хэта по сетке; она доступна также в Piano Roll для ударных.
- **MIDI variation…** меняет фразировку, ритм или оба параметра. Сохраняет раскладку клипов, инструменты и темп исходника, не транспонирует ноты на произвольные полутона.
- **New melody in a MIDI arrangement…** строит новые мелодические партии и гармонию поверх раскладки исходного MIDI. Сохраняет его инструменты, клипы (позиции и длины), изменения темпа и партию ударных, если она была. Как и обычный импорт SPESSA, не переносит всю MIDI-автоматику.

MIDI обрабатывается локально, без загрузки на сервер. Чтобы повторить генерацию, используйте те же настройки и число **Seed**. Для непустого проекта SPESSA сначала предложит сохранить его в браузере; отмена оставит редактор без изменений. Результат открывается в аранжировщике: можно править отдельные ноты и клипы, сохранить проект или экспортировать MIDI. **Undo** возвращает проект, который был открыт до генерации.

### Перенос в трекер

**File → Export MIDI (separate tracks)…** создаёт MIDI формата 1: темп и размер идут отдельной служебной дорожкой, а каждая звучащая партия — своей дорожкой с именем. Обычный **Save As MIDI…** сохраняет прежний формат. В трекере с поддержкой MIDI используйте эти дорожки как исходник: например, Lead → Pulse 1, Chords → Pulse 2, Bass → Triangle, Drums → Noise. **Pulse 2 монофонический**: аккорды нужно превратить в арпеджио или выбрать один голос. MIDI-ударные нужно назначить на звуки Noise вручную. SPESSA не создаёт NSF напрямую.

## Редактирование композиции

- **File → New Project / Open Project… / Open MIDI…** — создать проект с одной дорожкой ударных, открыть сохранённый в этом браузере проект или импортировать MIDI. Начальный темп проекта виден в **BPM** слева от **SR**. **Save As MIDI…** экспортирует размещённые клипы целиком.
- **Имя канала слева** открывает его пиано-ролл. Двойной щелчок по клипу открывает именно его паттерн. **+ ADD** под каналами создаёт канал. Кнопка **Instrument** назначает этому каналу либо инструмент (класс и пресет), либо набор ударных. Ноты при смене звука остаются на месте.
- **Сетка аранжировщика:** левая кнопка на пустом месте рисует клип, перетаскивание клипа перемещает его по тактам, правая кнопка удаляет его. Кнопка **← Arranger** возвращает из пиано-ролла.
- **New pattern** создаёт следующий паттерн канала (`10.1`, `10.2`, …). После импорта MIDI по умолчанию это один такт в размере исходника. Поле **Bars** меняет длину выбранного паттерна во всех его клипах и не даёт обрезать ноты или наложить клипы друг на друга; **Delete pattern** удаляет паттерн во всех его размещениях. **Edit → Undo/Redo** (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z) хранит историю текущего проекта в этой вкладке.
- **Snap → Grid / ⅓ step / Free** задаёт точность перемещения и изменения длины нот; **Alt** временно отключает привязку. Такты и группы из четырёх шагов выделены разными оттенками.
- **Generate** справа от **Delete pattern** заполняет текущий паттерн редактируемыми нотами. Для мелодического канала выберите тональность, лад и ритм (аккорды, мелодию, арпеджио или синкопы); для ударных — грув. Если ноты уже есть, их можно сохранить и добавить новые либо заменить целиком. Генерацию можно отменить через **Undo**.
- Повторные клипы ссылаются на один паттерн: правка нот в пиано-ролле слышна во всех его копиях. Удаление клипа не удаляет ноты самого паттерна.
- **Ctrl/Cmd+C, X, V** (или **Edit**) копируют, вырезают и вставляют выбранные ноты. Клик по линейке пиано-ролла также задаёт позицию вставки; без него редактор ищет свободное место в паттерне.
- **Player → Open Player… / F5** проигрывает исходный MIDI из плейлиста, не трогая проект. В оверлее можно добавлять файлы, ставить воспроизведение на паузу, перематывать и переключать треки. Если в оригинале пропадают голоса, включите **Compatible**: он разводит партии по отдельным каналам и подбирает доступные пресеты SoundFont, но не переносит всю MIDI-автоматику.
- **File → Open MIDI…** создаёт редактируемую аранжировку: ноты сгруппированы по каналам и инструментам, точные повторы используют общий паттерн. Если на дорожке несколько паттернов, выделите нужный клип и нажмите имя канала слева. Для точного воспроизведения исходного файла, включая его MIDI-автоматику, используйте плеер.

- Клик по верхней линейке аранжировщика или пиано-ролла ставит головку воспроизведения. Если музыка играет, она продолжает играть с нового места; если остановлена, следующее **Play** начнётся с выбранной позиции. Кнопки **⏮/⏭** ставят головку в начало или конец.
- При импорте дорожки, повторно использующие MIDI-канал, и партии с разными программами получают отдельные дорожки. При необходимости создаются дополнительные MIDI-порты, чтобы партии за пределами первых 16 не сливались.

- ПКМ по верхней полосе маркеров сводит их и отключает повтор диапазона. Потяните левый маркер влево, затем правый вправо. Кнопка **Loop entire track** слева от **Loop** ставит диапазон от начала до конца звучащей части. Если изменить клипы во время проигрывания, аранжировка обновится без ручного Stop/Play.
- В Piano Roll слева от общей громкости индикатор показывает состояние текущего канала: зелёный **ON** или серый **MUTE**. Изменить состояние можно в микшере.
- Микшер слева от транспорта. В редакторе он управляет каналами проекта, в плеере — портами и каналами текущего MIDI, не меняя проект. В окне **Instrument** фильтр банков показывает доступные банки загруженного SoundFont, когда их больше одного.

- ПКМ по имени канала → **Draw pattern** выбирает паттерн, который рисуется на пустой сетке. Его имя также видно в подсказке канала.
- Для визуальных пометок выберите **Comment** в категории канала. Откройте паттерн и заполните **Notes**: текст будет виден в клипах и сохранится с проектом, но не попадёт в MIDI или в микшер. Потяните правый край клипа, чтобы изменить длину паттерна в целых тактах: минимум один такт, максимум — без наложения на соседние клипы. Изменение применяется ко всем копиям и отменяется через Undo.

- При воспроизведении аранжировки головка идёт до центра видимой сетки, а затем сетка прокручивается за ней. **Pause** оставляет позицию, **Stop** и **To start** возвращают вид к началу. **To start** выключает короткий луп, не стирая его границы. Повтор можно снова включить кнопкой **Loop**. **To end** останавливает воспроизведение и оставляет головку в конце трека; настройки лупа сохраняются.
